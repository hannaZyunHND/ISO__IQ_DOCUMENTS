# BM-285: Bảng Sao Vàng (Template)

## Thông tin biểu mẫu
- **Mã biểu mẫu**: QT-06-SOP-03-BM-04
- **Tên biểu mẫu**: Bảng Sao Vàng (Template)
- **Phiên bản**: 1.0
- **Ngày ban hành**: 30/10/2025
- **Ngày hiệu lực**: 30/10/2025
- **SOP liên quan**: SOP-03.2

## Mục đích
Template bảng Sao Vàng để GVCN treo trong lớp, ghi nhận hành vi tích cực của HS.

## Nội dung biểu mẫu

```
═══════════════════════════════════════════════════════
         BẢNG SAO VÀNG LỚP __
═══════════════════════════════════════════════════════

HƯỚNG DẪN TÍCH SAO:
• Đến đúng giờ: +1 ⭐
• Nộp bài đúng hạn: +1 ⭐
• Giúp bạn: +2 ⭐
• Làm bài tốt (Điểm 9-10): +2 ⭐
• Nhặt rác: +1 ⭐
• Tuân thủ quy định cả tuần: +5 ⭐

ĐỔI THƯỞNG:
• 10 ⭐ → 1 Sticker
• 50 ⭐ → 1 Bút chì / Tẩy
• 100 ⭐ → 1 Quyển vở / Bộ bút màu
• 200 ⭐ → Giấy khen + Quà lớn

BẢNG TÍCH SAO:

┌──────────┬──────┬──────┬──────┬──────┬──────┬──────────┐
│ Tên HS   │ T2   │ T3   │ T4   │ T5   │ T6   │ TỔNG     │
├──────────┼──────┼──────┼──────┼──────┼──────┼──────────┤
│Nguyễn VA │ ⭐⭐ │ ⭐   │ ⭐⭐⭐│ ⭐   │ ⭐  │   9⭐     │
│Trần Thị B│ ⭐   │ ⭐⭐ │ ⭐   │ ⭐⭐ │⭐⭐  │   8⭐     │
│Lê Văn C  │ ⭐⭐⭐│ ⭐⭐ │ ⭐⭐⭐│ ⭐⭐⭐│ ⭐⭐ │  13⭐     │
│Phạm Thị D│ ⭐   │ ⭐   │ ⭐⭐ │ ⭐   │ ⭐  │   6⭐     │
│...       │      │      │      │      │      │          │
└──────────┴──────┴──────┴──────┴──────┴──────┴──────────┘

GVCN: _____________________
═══════════════════════════════════════════════════════
```

## Hướng dẫn sử dụng
1. In bảng treo trên tường lớp
2. Mỗi ngày GVCN dán sao cho HS
3. Cuối tuần/tháng tổng hợp và đổi thưởng
4. Cập nhật thường xuyên

## Lưu ý
- Công bằng cho tất cả HS
- Ghi rõ lý do tích sao
- Khuyến khích HS tích cực
