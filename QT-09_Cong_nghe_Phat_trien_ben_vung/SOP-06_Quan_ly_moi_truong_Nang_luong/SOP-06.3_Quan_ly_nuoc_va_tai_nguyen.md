# SOP-06.3: QUẢN LÝ NƯỚC VÀ TÀI NGUYÊN

## 2. WATER MANAGEMENT

### 2.1. Water audit

#### 2.1.1. Baseline measurement
```
Thu thập data:
1. Consumption:
   - Monthly bills
   - m³ per month
   - Cost per m³

2. Usage breakdown:
   - Toilets: [X%]
   - Landscape: [Y%]
   - Kitchen: [Z%]
   - Drinking: [W%]
   - Cleaning: [V%]
   - Other: [U%]

3. Benchmarking:
   - Liters per student per day
   - Compare với similar schools
   - Identify high usage
```

### 2.2. Water conservation

#### 2.2.1. Fixtures và equipment
```
Upgrades:
1. Toilets:
   - Dual-flush (3L/6L)
   - Low-flow (4.8L vs. 9L)
   - Sensors (auto-flush)
   - Savings: 30-50%

2. Faucets:
   - Aerators (reduce flow)
   - Sensor faucets (auto off)
   - Foot-operated (kitchens)
   - Savings: 20-30%

3. Urinals:
   - Waterless (nếu appropriate)
   - Low-flow
   - Sensors

4. Drinking fountains:
   - Bottle fillers (efficient)
   - Chilled water (reduce bottled)
```

#### 2.2.2. Landscape irrigation
```
Strategies:
1. Drip irrigation:
   - Efficient watering
   - 50% savings vs. sprinklers

2. Smart irrigation:
   - Moisture sensors
   - Weather-based
   - Scheduled watering

3. Plant selection:
   - Native plants (less water)
   - Drought-resistant
   - Appropriate for climate

4. Mulching:
   - Retain moisture
   - Reduce watering frequency

Target: 40% reduction trong irrigation
```

### 2.3. Leak detection và repair

#### 2.3.1. Leak detection
```
Methods:
- Regular inspections (weekly)
- Meter monitoring (after-hours flow)
- Moisture sensors (expensive areas)
- User reports

Immediate fix:
- Repair within 24h
- Track repairs
- Prevent water loss
```

## 3. RAINWATER HARVESTING

### 3.1. System design
```
Components:
1. Collection:
   - Roof catchment
   - Gutters và downpipes
   - Leaf guards

2. Storage:
   - Underground tanks
   - Capacity: 50-100 m³
   - Overflow to drainage

3. Treatment (nếu cần):
   - Filtration
   - Disinfection (UV)

4. Distribution:
   - Pumps
   - Separate piping
   - Irrigation system
```

### 3.2. Usage
```
Non-potable uses:
- Landscape irrigation (primary)
- Toilet flushing (nếu treated)
- Cleaning
- Fire reserve

Potential: 30-50% of total water needs
```

## 4. WASTEWATER MANAGEMENT

### 4.1. Greywater recycling

#### 4.1.1. System
```
Sources:
- Sinks
- Showers (nếu có)
- Drinking fountains

Treatment:
- Filtration
- Disinfection

Reuse:
- Toilet flushing
- Irrigation

Savings: 20-30% of total water
```

## 5. WATER QUALITY

### 5.1. Drinking water
```
Monitoring:
- Test monthly (in-house)
- Test quarterly (lab)
- Parameters: pH, turbidity, bacteria, chemicals

Standards:
- QCVN 01:2009/BYT (Drinking water)
- WHO guidelines

Actions if fails:
- Stop use immediately
- Notify authorities
- Investigate cause
- Remediate
- Re-test before resuming
```
