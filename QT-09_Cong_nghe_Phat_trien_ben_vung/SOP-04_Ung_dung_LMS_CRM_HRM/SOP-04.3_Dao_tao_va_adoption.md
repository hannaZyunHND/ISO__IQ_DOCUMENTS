# SOP-04.3: ĐÀO TẠO VÀ ADOPTION

## 1. MỤC ĐÍCH
Quy định quy trình đào tạo và thúc đẩy chấp nhận hệ thống mới, đảm bảo:
- Users biết cách sử dụng hiệu quả
- Adoption rate cao
- Resistance được quản lý
- Value được realize
- Continuous learning

## 2. CHANGE MANAGEMENT

### 2.1. Change readiness assessment
```
Assess before go-live:
- User sentiment (survey)
- Resistance level
- Concerns và fears
- Support needed
- Champions identified

Result: Readiness score (1-5)
- ≥4: Ready
- 3-4: Need more preparation
- <3: Delay go-live
```

### 2.2. Stakeholder management

#### 2.2.1. Stakeholder mapping
```
Power/Interest Matrix:

High Power, High Interest:
- Manage closely (BGH, Department heads)

High Power, Low Interest:
- Keep satisfied (Board)

Low Power, High Interest:
- Keep informed (Teachers, staff)

Low Power, Low Interest:
- Monitor (Students)
```

#### 2.2.2. Communication plan
```
Pre-launch (3 tháng):
- Announcement email
- Town halls
- FAQs published
- Feedback sessions

During rollout:
- Weekly updates
- Success stories
- Tips và tricks
- Support available

Post-launch:
- Metrics sharing
- Continuous tips
- Advanced features
- Feedback loops
```

## 3. TRAINING PROGRAM

### 3.1. Training strategy

#### 3.1.1. Tiered approach
```
Tier 1 - Super users (20-30 người):
- 2-3 ngày intensive training
- Vendor-led + hands-on labs
- Advanced features
- Become trainers và support

Tier 2 - Power users (50-100 người):
- 1 ngày training
- Core features
- Their workflows
- Practice exercises

Tier 3 - End users (all):
- 2-4 giờ training
- Basic functions
- Self-service
- Quick reference
```

#### 3.1.2. Training modes
```
Instructor-led:
- Classroom sessions
- Interactive
- Q&A
- Hands-on practice

E-learning:
- Online modules
- Self-paced
- Videos
- Quizzes

On-demand:
- Knowledge base
- Video library
- Quick reference guides
- Tooltips trong system
```

### 3.2. Training curriculum

#### 3.2.1. LMS training (for Teachers)
```
Session 1: Basics (2 giờ)
- Logging in
- Dashboard overview
- Creating a course
- Adding content
- Basic settings

Session 2: Content (2 giờ)
- Uploading materials
- Creating assignments
- Building quizzes
- Discussion forums
- Grading

Session 3: Advanced (2 giờ)
- Advanced features
- Analytics
- Mobile app
- Integration với tools
- Tips và tricks

Total: 6 giờ over 3 sessions
```

#### 3.2.2. CRM training (for Admissions)
```
Session 1: Basics (2 giờ)
- Lead management
- Contact records
- Activity logging
- Email integration

Session 2: Pipeline (2 giờ)
- Pipeline stages
- Moving leads
- Task management
- Reporting

Session 3: Advanced (2 giờ)
- Automation
- Campaigns
- Analytics
- Best practices

Total: 6 giờ over 3 sessions
```

#### 3.2.3. HRM training (for HR & Managers)
```
HR Staff (8 giờ):
- Complete system
- All modules
- Admin functions
- Reporting

Managers (4 giờ):
- Employee records (their team)
- Performance management
- Leave approval
- Reporting

Employees (1 giờ):
- Self-service portal
- Update info
- Submit leave
- Access documents
```

### 3.3. Training delivery

#### 3.3.1. Schedule
```
Pre-launch (4 tuần):
Week 1: Super users (Tier 1)
Week 2-3: Power users (Tier 2)
Week 4: End users (Tier 3)

Post-launch:
- Weekly office hours (first month)
- Monthly refresher sessions
- On-demand for new hires
```

#### 3.3.2. Training materials
```
Provide:
- Training manual (PDF)
- Quick reference card
- Video tutorials (5-10 phút each)
- Cheat sheets
- Practice environment
- FAQs
```

## 4. ADOPTION STRATEGY

### 4.1. Champions program

#### 4.1.1. Recruit champions
```
Criteria:
- Enthusiastic về system
- Respected by peers
- Good communicators
- Tech-savvy
- Available to help

Select: 10-15 champions (1 per department)
```

#### 4.1.2. Champion activities
```
Responsibilities:
- Complete advanced training
- Support peers
- Gather feedback
- Share best practices
- Promote adoption
- Report issues

Support:
- Dedicated training
- Regular meetings
- Direct line to IT
- Recognition
- Incentives
```

### 4.2. Incentives và motivation

#### 4.2.1. Positive reinforcement
```
Rewards:
- Recognition (public praise)
- Certificates (power users)
- Prizes (contests, quizzes)
- Early access (new features)
- Influence (beta testing, feedback)
```

#### 4.2.2. Gamification
```
Elements:
- Points (for activities)
- Badges (achievements)
- Leaderboards (top users)
- Challenges (weekly goals)
- Rewards (tangible)

Track:
- Login frequency
- Feature usage
- Content created
- Engagement
```

### 4.3. Mandates và enforcement

#### 4.3.1. Mandatory usage
```
Set clear expectations:
- What must be done trong system
- Deadlines
- Consequences

Examples:
- Grades must be entered trong LMS (not Excel)
- Leads must be tracked trong CRM
- Leave requests must be through HRM
```

#### 4.3.2. Phased mandate
```
Phase 1 (Month 1-2): Voluntary
- Encourage usage
- Support early adopters
- Gather feedback

Phase 2 (Month 3-4): Soft mandate
- Strong encouragement
- Incentives
- Track non-users

Phase 3 (Month 5+): Hard mandate
- Required
- Old system sunset
- Enforcement
```
