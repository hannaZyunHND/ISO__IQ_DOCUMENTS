## 4. PHISHING AWARENESS

### 4.1. Phishing simulation program

#### 4.1.1. Campaign structure
```
Frequency: Monthly

Process:
1. Select template (varied difficulty)
2. Target audience (all staff)
3. Send simulated phishing email
4. Track clicks và submissions
5. Immediate training (những người click)
6. Report results
7. Adjust training
```

#### 4.1.2. Simulation scenarios
```
Easy (Awareness):
- Generic phishing (obvious errors)
- Unknown sender
- Poor formatting

Medium (Realistic):
- Looks professional
- Spoofed sender
- Timely topic

Hard (Advanced):
- Spear phishing (personalized)
- Clone phishing (replicate real emails)
- Business email compromise
```

#### 4.1.3. Response to clickers
```
Immediate (tự động):
- Redirect to training page
- Explain why it was phishing
- Tips to identify
- Mark as training (not punishment)

Follow-up:
- Additional training (nếu >2 lần/quarter)
- 1-1 coaching (nếu persistent)
```

### 4.2. Real phishing handling

#### 4.2.1. User actions
```
If suspicious email:
1. Không click links
2. Không download attachments
3. Report to IT (forward to security@...)
4. Delete email
```

#### 4.2.2. IT response
```
Upon report:
1. Analyze email (within 30 phút)
2. If phishing:
   - Block sender
   - Remove from all mailboxes
   - Alert users
   - Update filters
3. Thank reporter
4. Track và report
```

## 6. SPECIAL TRAINING

### 6.1. New hire training
```
Timing: During onboarding

Content (60 phút):
- Security policies overview
- Access responsibilities
- Data protection basics
- Incident reporting
- Q&A
- Sign acknowledgment

Mandatory: Must complete before access granted
```

### 6.2. Incident response drills

#### 6.2.1. Tabletop exercises
```
Frequency: Quarterly

Format:
- Scenario-based discussion (2-3 giờ)
- No actual systems involved
- Walk through response steps
- Identify gaps
- Improve procedures

Scenarios:
- Ransomware attack
- Data breach
- DDoS
- Insider threat
```

#### 6.2.2. Live drills
```
Frequency: Annual

Format:
- Simulated attack (red team)
- IRT responds (blue team)
- Observe và evaluate
- Debrief
- Improve

Scope:
- Full incident response process
- All team members
- Real systems (safe mode)
```
