# SOP-07.5: ĐO LƯỜNG VÀ BÁO CÁO IMPACT

## 1. MỤC ĐÍCH
Quy định quy trình đo lường và báo cáo impact của CSR, đảm bảo:
- Tracking kết quả chính xác
- Đo lường impact thực sự
- Báo cáo minh bạch
- Học hỏi và cải tiến
- Trách nhiệm giải trình

## 2. IMPACT MEASUREMENT FRAMEWORK

### 2.1. Theory of Change

#### 2.1.1. Logic model
```
INPUTS → ACTIVITIES → OUTPUTS → OUTCOMES → IMPACT

Inputs (Resources):
- Budget
- Staff time
- Volunteers
- Partners
- Materials

Activities (What we do):
- Training sessions
- Tutoring
- Health camps
- Cleanups
- Advocacy

Outputs (Direct results):
- # people trained
- # hours tutoring
- # patients served
- # kg waste collected
- # people reached

Outcomes (Short-mid term changes):
- Knowledge gained
- Skills improved
- Behavior changed
- Services accessed

Impact (Long-term change):
- Lives transformed
- Community improved
- System changed
- Problem addressed
```

### 2.2. Impact indicators

#### 2.2.1. By focus area
```
Education Access:
- Students enrolled (because of support)
- Literacy rates improved
- Dropout rates reduced
- Test scores improved
- Teachers trained

Community Development:
- Income increased
- Skills acquired
- Employment gained
- Facilities built/improved
- Community capacity strengthened

Environment:
- Waste reduced/recycled
- Trees planted (survived)
- Carbon offset
- Habitats restored
- Awareness increased

Social Welfare:
- Lives improved
- Health outcomes
- Social inclusion
- Quality of life
```

## 3. DATA COLLECTION

### 3.1. Methods

#### 3.1.1. Quantitative data
```
Methods:
- Surveys (pre/post)
- Tests/assessments
- Administrative records (attendance, grades)
- Observation checklists
- Meter readings (energy, water, waste)

When: Baseline, midline, endline
Sample: All beneficiaries or representative sample
```

#### 3.1.2. Qualitative data
```
Methods:
- Interviews (in-depth)
- Focus groups
- Case studies (stories)
- Observations (ethnographic)
- Open-ended survey questions

Purpose: Understand "how" và "why", capture nuances
```

### 3.2. Data management

#### 3.2.1. Data collection plan
```
For each project:
- What data? (indicators)
- How collect? (methods)
- When? (timing)
- Who? (responsibility)
- How analyze? (tools, approach)
- How store? (database, security)

Document: Data collection plan (DCP)
```

#### 3.2.2. Data quality
```
Ensure:
- Validity (measures what intended)
- Reliability (consistent)
- Completeness (minimal missing)
- Accuracy (correct)
- Timeliness (collected on schedule)

Methods:
- Training data collectors
- Pilot testing tools
- Supervision
- Verification (spot checks)
- Cleaning (fix errors)
```

## 4. ANALYSIS

### 4.1. Quantitative analysis

#### 4.1.1. Descriptive statistics
```
Calculate:
- Frequencies (counts, percentages)
- Central tendency (mean, median)
- Dispersion (range, standard deviation)
- Trends (over time)

Tools: Excel, SPSS, R
```

#### 4.1.2. Impact analysis
```
Methods:
- Pre-post comparison (same group)
- Control group comparison (with vs. without intervention)
- Statistical tests (t-test, chi-square)
- Effect size (Cohen's d)

Question: Did intervention cause change?
```

### 4.2. Qualitative analysis

#### 4.2.1. Thematic analysis
```
Steps:
1. Transcribe (interviews, focus groups)
2. Read và familiarize
3. Code (identify themes)
4. Categorize (group codes)
5. Interpret (meaning)
6. Write up (narrative, quotes)

Tools: NVivo, Atlas.ti, or manual
```

### 4.3. Synthesis

#### 4.3.1. Integrated findings
```
Combine:
- Quantitative (what, how much)
- Qualitative (how, why)
- Triangulate (multiple sources confirm)

Output: Comprehensive understanding of impact
```

## 5. REPORTING

### 5.1. Internal reporting

#### 5.1.1. Project reports
```
QUARTERLY PROJECT REPORT

1. EXECUTIVE SUMMARY (1 trang)
   - Project overview
   - Progress highlights
   - Key results
   - Issues và actions

2. ACTIVITIES (2 trang)
   - What done
   - Who reached
   - Outputs achieved

3. OUTCOMES (2 trang)
   - Changes observed
   - Data/evidence
   - Compared to targets

4. LEARNINGS (1 trang)
   - What worked
   - Challenges
   - Adjustments

5. FINANCIALS (1 trang)
   - Budget vs. actual
   - Variance explanation

6. NEXT STEPS
```

#### 5.1.2. Annual CSR report
```
CSR ANNUAL REPORT (20-30 trang)

1. Message from Principal
2. CSR overview (strategy, pillars)
3. Year in numbers (infographic)
4. By focus area:
   - Education access
   - Community development
   - Environment
   - Social welfare
   (Activities, outputs, outcomes, stories)
5. Student service learning
6. Partnerships
7. Financial summary
8. Impact highlights (case studies)
9. Challenges và learnings
10. Next year priorities
11. Thank you (partners, volunteers)
12. Appendix (detailed data)
```

### 5.2. External reporting

#### 5.2.1. Public report
```
Format:
- PDF (website download)
- Infographic (visual summary)
- Video (3-5 phút highlights)
- Social media posts (key stories)

Content:
- Achievements (data)
- Stories (beneficiaries, students)
- Photos (activities, impact)
- Thank you (partners, donors)

Audience: Parents, community, media, potential partners
```

#### 5.2.2. Donor/partner reports
```
Customized reports:
- Focus on their contribution
- Results achieved (because of them)
- Stories related to their support
- Photos (their logo featured)
- Thank you và recognition

Timing: After project completion, annually
```

## 6. IMPACT STORIES

### 6.1. Case studies

#### 6.1.1. Story development
```
Select:
- Representative (typical impact)
- Compelling (emotionally resonant)
- Diverse (different beneficiaries, projects)

Structure:
1. Before (situation, challenges)
2. Intervention (what we did)
3. After (changes, transformation)
4. Impact (difference made)
5. Voice (quotes from beneficiary)

Format: 300-500 words, photos
```

### 6.2. Storytelling

#### 6.2.1. Ethical storytelling
```
Principles:
- Consent (permission to share story)
- Dignity (respectful portrayal)
- Accuracy (factual, not exaggerated)
- Privacy (anonymize if sensitive)
- Empowerment (beneficiary as agent, not victim)

Avoid:
- "Poverty porn" (exploitative imagery)
- Savior narrative (we rescued them)
- Stereotypes
```

## 7. LEARNING VÀ IMPROVEMENT

### 7.1. Learning review

#### 7.1.1. After-action review
```
After each project (1-2 giờ session):
Questions:
- What intended? (objectives)
- What actually happened? (reality)
- What worked well? (successes)
- What didn't? (challenges)
- Why? (root causes)
- What learned? (insights)
- What change? (improvements)

Participants: Project team, partners, students
Document: Lessons learned log
```

### 7.2. Knowledge management

#### 7.2.1. Best practices
```
Capture:
- Effective approaches
- Tools that worked
- Innovations
- Mistakes to avoid

Share:
- Internal (knowledge base)
- External (presentations, publications)
- Training (new staff, students)

Apply: Incorporate into future projects
```

## 8. IMPACT EVALUATION

### 8.1. Rigorous evaluation

#### 8.1.1. Types
```
Formative evaluation:
- During project (improve implementation)
- Questions: Is it working? How improve?

Summative evaluation:
- End of project (assess overall impact)
- Questions: Did it work? Should continue?

Methods:
- Surveys
- Interviews
- Focus groups
- Data analysis
- External evaluator (for major projects)
```
