# SOP-07.3: SERVICE LEARNING CHO HỌC SINH

## 1. MỤC ĐÍCH
Quy định quy trình service learning (học tập qua phục vụ cộng đồng), đảm bảo:
- Kết hợp học thuật và phục vụ
- Phát triển năng lực công dân
- Trải nghiệm thực tế ý nghĩa
- Reflection và learning
- Impact cho cộng đồng

## 2. SERVICE LEARNING PHILOSOPHY

### 2.1. Definition
```
Service Learning = Service + Learning

Service:
- Address real community needs
- Benefit others (not just self)
- Meaningful contribution

Learning:
- Connected to curriculum
- Structured reflection
- Skill development
- Understanding issues deeper

Both essential: Not just volunteering, not just academics
```

### 2.2. Learning outcomes
```
Students will develop:
- Civic responsibility và compassion
- Understanding of social issues
- Critical thinking về solutions
- Collaboration và teamwork
- Leadership và initiative
- Communication skills
- Self-awareness và growth
- Career exploration
```

## 3. CURRICULUM INTEGRATION

### 3.1. By grade level

#### 3.1.1. Elementary (Grades 1-5)
```
Approach: Class-based projects

Examples:
- Grade 1-2: Animal shelter visit, donations
- Grade 3-4: Elderly home visits, performances
- Grade 5: Environmental cleanup, poster campaigns

Duration: 2-4 sessions/năm
Hours: 5-10 hours/năm
Supervision: Teacher-led, high support
```

#### 3.1.2. Middle School (Grades 6-8)
```
Approach: Mix of class projects và individual choice

Requirements:
- Grade 6-8: 20 hours/năm service
- 50% class projects, 50% individual choice

Examples:
- Tutoring younger students
- Community garden
- Library assistance
- Beach cleanups
- Fundraising events

Supervision: Teacher + student initiative
```

#### 3.1.3. High School (Grades 9-12)
```
Approach: Individual initiative, sustained engagement

Requirements:
- Total: 100 hours (over 4 years)
- Grade 9-10: 20 hours/năm
- Grade 11-12: 30 hours/năm
- ≥ 50% trong one sustained project (depth)

Examples:
- Teaching assistant (partner school)
- NGO internship
- Student-led initiatives
- Research projects (social issues)
- Advocacy campaigns

Supervision: Faculty advisor, student-driven
```

### 3.2. Subject integration

#### 3.2.1. Cross-curricular connections

```
Science:

Math:

Arts:

```

## 4. SERVICE LEARNING PROCESS

### 4.1. Planning phase

#### 4.1.1. Student involvement
```
Steps:
1. Explore issues (research, discussions)
2. Identify community needs (surveys, interviews)
3. Brainstorm project ideas
4. Select project (voting, consensus)
5. Define objectives (what achieve?)
6. Plan activities (who, what, when, where)
7. Prepare (training, materials)

Teacher role: Facilitate, guide, connect
```

### 4.2. Action phase

#### 4.2.1. Implementation
```
During service:
- Students lead activities
- Engage authentically với beneficiaries
- Collaborate với partners
- Adapt as needed
- Document (photos, journals)

Teacher role: Supervise, support, observe
```

### 4.3. Reflection phase

#### 4.3.1. Structured reflection
```
When: Before, during, after service

Methods:
- Journaling (prompts)
- Discussion circles (class)
- Presentations (share experiences)
- Creative expression (art, poetry, video)
- Essays (connect to learning)

Prompts:
- What did you do? (describe)
- What did you observe? (notice)
- What did you feel? (emotional)
- What did you learn? (academic, personal)
- How does it connect to [subject]?
- What surprised you?
- What challenged you?
- What changed trong your thinking?
- What will you do differently?
- How will you continue?
```

### 4.4. Celebration phase

#### 4.4.1. Recognition
```
Showcase:
- Service learning fair (annual)
- Presentations (assembly)
- Awards (outstanding service)
- Certificates (hours completed)
- Features (newsletter, social media)

Purpose: Celebrate, inspire, share learning
```

## 5. PROJECT TYPES

### 5.1. Direct service
```
Students provide service directly:
- Tutoring
- Mentoring
- Elderly care
- Disability support
- Teaching (skills, language)

Learning: Empathy, interpersonal skills, patience
```

### 5.2. Indirect service
```
Students support organizations:
- Fundraising
- Material collection
- Awareness campaigns
- Event organization
- Administrative support

Learning: Project management, marketing, operations
```

### 5.3. Advocacy
```
Students raise awareness, influence change:
- Research (social issues)
- Campaigns (public awareness)
- Policy proposals (student voice)
- Media (documentaries, articles)

Learning: Critical thinking, communication, civic action
```

### 5.4. Community-based research
```
Students conduct research benefiting community:
- Needs assessments
- Impact evaluations
- Best practices studies
- Data collection (community)

Learning: Research skills, data analysis, real-world application
```

## 6. SUPERVISION & SUPPORT

### 6.1. Faculty advisors
```
Role:
- Guide project selection
- Connect với partners
- Supervise activities (safety)
- Facilitate reflection
- Assess learning
- Verify hours

Assignment:
- 1 advisor per 10-15 students (high school)
- Class teachers (elementary, middle)

Training: Service learning pedagogy, reflection facilitation
```

### 6.2. Safety và logistics
```
Requirements:
- Risk assessment (all projects)
- Parental consent (minors)
- Transportation arranged
- Supervision ratios (1:10-15)
- Emergency contacts
- First aid available
- Insurance coverage

For international service:
- Additional approvals
- Travel insurance
- Health precautions
- Cultural preparation
```

## 7. ASSESSMENT

### 7.1. Learning assessment

#### 7.1.1. Evaluation criteria
```
Assess:
- Participation (effort, attendance)
- Reflection quality (depth, insight)
- Learning outcomes achieved
- Collaboration (teamwork)
- Initiative (leadership, problem-solving)
- Impact contribution

Not assessed:
- Hours quantity (above minimum)
- Service quality (beyond student control)
```

#### 7.1.2. Rubrics
```
Use rubrics for:
- Reflection essays/presentations
- Project reports
- Collaboration (peer/self evaluation)
- Learning outcomes (competencies)

Scoring: 4-point scale (Exemplary, Proficient, Developing, Beginning)
```

### 7.2. Recognition

#### 7.2.1. Transcript notation
```
Service learning appears on transcript:
- Hours completed (verified)
- Projects participated
- Leadership roles
- Awards received

Purpose: College applications, scholarships
```
