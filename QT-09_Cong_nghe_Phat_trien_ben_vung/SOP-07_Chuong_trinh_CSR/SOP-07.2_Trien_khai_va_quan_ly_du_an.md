# SOP-07.2: TRIỂN KHAI VÀ QUẢN LÝ DỰ ÁN

## 1. MỤC ĐÍCH
Quy định quy trình triển khai và quản lý dự án CSR, đảm bảo:
- Thực hiện đúng kế hoạch
- Quản lý nguồn lực hiệu quả
- Theo dõi tiến độ
- Giải quyết vấn đề kịp thời
- Đạt mục tiêu đề ra

## 2. PROJECT SETUP

### 2.1. Project team

#### 2.1.1. Team structure
```
Project Manager (1):
- Overall responsibility
- Coordination
- Reporting

Core team (3-5):
- Planning
- Implementation
- Monitoring

Student volunteers (10-30):
- Activities execution
- Peer mobilization

Partner representatives (1-2):
- Liaison
- Expertise
- Access
```

#### 2.1.2. Roles và responsibilities
```
Project Manager:
- Develop detailed plan
- Manage budget
- Coordinate partners
- Monitor progress
- Report to committee
- Risk management

Team members:
- Execute activities
- Collect data
- Support volunteers
- Document progress

Students:
- Participate trong activities
- Engage beneficiaries
- Learn và reflect
- Share experiences
```

### 2.2. Detailed planning

#### 2.2.1. Work breakdown structure
```
Decompose project:
- Major phases
- Activities per phase
- Tasks per activity
- Deliverables

Estimate:
- Duration per task
- Resources needed
- Dependencies
- Milestones
```

#### 2.2.2. Project schedule
```
Use Gantt chart:
- All activities listed
- Start/end dates
- Dependencies
- Milestones marked
- Critical path identified

Tools: MS Project, Asana, Smartsheet
```

## 3. IMPLEMENTATION

### 3.1. Kickoff

#### 3.1.1. Internal kickoff
```
Meeting agenda (2 giờ):
1. Project overview (15 phút)
2. Objectives và expected impact (15 phút)
3. Roles và responsibilities (20 phút)
4. Timeline và milestones (20 phút)
5. Logistics (15 phút)
6. Q&A (20 phút)
7. Team building (15 phút)

Attendees:
- Project team
- Volunteers
- Relevant staff

Output: Everyone clear on roles, excited
```

#### 3.1.2. External kickoff (với partners/community)
```
Meeting agenda (2-3 giờ):
1. Introductions
2. Project overview
3. Partnership roles
4. Communication plan
5. Timeline
6. Community engagement approach
7. Next steps

Attendees:
- Project team
- Partners
- Community leaders
- Beneficiaries (representatives)

Output: MOU signed, relationships established
```

### 3.2. Execution

#### 3.2.1. Activity implementation
```
For each activity:
1. Pre-activity prep:
   □ Materials ready
   □ Venue confirmed
   □ Volunteers briefed
   □ Partners coordinated
   □ Beneficiaries informed

2. During activity:
   □ Execute as planned
   □ Monitor quality
   □ Document (photos, notes)
   □ Collect data
   □ Adjust as needed

3. Post-activity:
   □ Debrief team
   □ Thank participants
   □ Process data
   □ Update records
   □ Report
```

#### 3.2.2. Quality assurance
```
Ensure:
- Activities meet standards
- Beneficiaries satisfied
- Partners engaged
- Students learning
- Safety maintained

Methods:
- Checklists
- Observations
- Feedback forms
- Quality reviews
```

## 4. MONITORING & CONTROL

### 4.1. Progress tracking

#### 4.1.1. Weekly updates
```
Project Manager tracks:
- Activities completed vs. planned
- Budget spent vs. allocated
- Issues encountered
- Next week plans

Format: Short email update
Audience: Core team, CSR Manager
```

#### 4.1.2. Monthly reviews
```
Team meeting (1 giờ):
- Progress review (dashboard)
- Discuss challenges
- Problem-solving
- Adjust plan if needed
- Celebrate wins

Document: Meeting minutes
```

### 4.2. Performance metrics

### 4.3. Issue management

#### 4.3.1. Issue log
```
Track all issues:
- ID
- Description
- Impact (High/Med/Low)
- Who responsible
- Mitigation plan
- Status (Open/Closed)
- Resolution date

Review weekly: Close resolved, escalate critical
```

## 5. STAKEHOLDER MANAGEMENT

### 5.1. Communication plan

#### 5.1.1. Internal communication
```
Audience | Frequency | Method | Content
---------|-----------|--------|--------
Team | Weekly | Email | Updates, tasks
Volunteers | Bi-weekly | WhatsApp | Activities, motivation
School | Monthly | Newsletter | Highlights, photos
Committee | Quarterly | Report | Progress, financials
BGH | Quarterly | Presentation | Strategic update
```

#### 5.1.2. External communication
```
Partners:
- Monthly: Email updates
- Quarterly: Face-to-face meetings
- As needed: Calls, messages

Beneficiaries:
- Before activities: Invitations, info
- During: Engagement, feedback
- After: Thank you, follow-up

Public:
- Social media: Weekly posts
- Website: Monthly updates
- Media: Major milestones
```

### 5.2. Volunteer management

#### 5.2.1. Recruitment
```
Process:
1. Call for volunteers (newsletter, assembly)
2. Application form (interest, availability)
3. Selection (balanced, committed)
4. Orientation (training)
5. Assignment (roles)

Target: 20-30 volunteers per project
```

#### 5.2.2. Support và retention
```
Provide:
- Clear roles
- Training
- Supervision
- Recognition (certificates, awards)
- Reflection opportunities
- Community (team bonding)

Goal: ≥ 80% retention through project
```

## 6. FINANCIAL MANAGEMENT

### 6.1. Budget tracking

#### 6.1.1. Expense management
```
Process:
1. All expenses pre-approved (within budget)
2. Receipts collected
3. Log expenses (spreadsheet)
4. Monthly reconciliation
5. Report variances (±10%)

Tools: Accounting software, Excel
```

#### 6.1.2. Budget categories
```
Track by:
- Activity
- Category (materials, transport, etc.)
- Month
- Partner (nếu có)

Compare: Planned vs. Actual
```

### 6.2. Financial reporting
```
Monthly:
- Expenses summary
- Budget status
- Forecast to completion

Quarterly:
- Detailed financial report
- Variance analysis
- Recommendations
```

## 7. RISK MANAGEMENT

### 7.1. Risk identification
```
Common CSR risks:
- Weather (outdoor activities)
- Low participation (beneficiaries)
- Partner issues (delays, conflicts)
- Funding shortfalls
- Safety incidents
- Reputational (bad publicity)

Identify early: Risk workshops, lessons learned
```

### 7.2. Mitigation
```
For each risk:
- Likelihood (H/M/L)
- Impact (H/M/L)
- Mitigation plan
- Contingency (if happens)
- Owner

Monitor: Risk register, regular reviews
```

## 8. PROJECT CLOSURE

### 8.1. Completion activities
```
Final phase:
□ Complete all activities
□ Collect final data
□ Final beneficiary feedback
□ Financial closure (pay vendors)
□ Thank partners và volunteers
□ Handover (nếu ongoing)
□ Document lessons learned
□ Final report
□ Celebration event
```

### 8.2. Post-project evaluation
```
Assess:
- Objectives achieved?
- Impact realized?
- Budget performance?
- Timeline adherence?
- What worked well?
- What to improve?
- Sustainability plan?

Method: Surveys, interviews, data analysis
Document: Project completion report
```
