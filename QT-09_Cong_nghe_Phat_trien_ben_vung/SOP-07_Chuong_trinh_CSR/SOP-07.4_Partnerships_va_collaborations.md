# SOP-07.4: PARTNERSHIPS VÀ COLLABORATIONS

## 1. MỤC ĐÍCH
Quy định quy trình xây dựng và quản lý partnerships cho CSR, đảm bảo:
- Hợp tác chiến lược hiệu quả
- Đóng góp bổ sung (complementary)
- Quan hệ bền vững
- Tăng impact
- Win-win outcomes

## 2. PARTNERSHIP STRATEGY

### 2.1. Partnership rationale
```
Why partner?
- Access (communities, expertise, resources)
- Legitimacy (community trust)
- Efficiency (avoid duplication)
- Scale (reach more)
- Learning (best practices)
- Sustainability (beyond project life)

When to partner:
- Gap trong expertise
- Access needed
- Resource constraints
- Shared objectives
- Strategic alignment
```

### 2.2. Partnership types

#### 2.2.1. NGO partnerships
```
Value:
- Deep community connections
- Social expertise
- Credibility
- Operational support

Examples:
- Education NGOs (literacy programs)
- Environmental NGOs (conservation)
- Health NGOs (clinics, awareness)
- Social welfare NGOs (orphanages, elderly)

Engagement: Project-based, long-term strategic
```

#### 2.2.2. Corporate partnerships
```
Value:
- Financial support (CSR budgets)
- In-kind contributions (products, services)
- Expertise (professional skills)
- Networks (connections)
- Volunteer employees

Examples:
- Tech companies (digital literacy)
- Banks (financial literacy)
- F&B (nutrition programs)
- Manufacturing (vocational training)

Engagement: Sponsorships, joint projects, pro bono
```

#### 2.2.3. Government partnerships
```
Value:
- Policy alignment
- Scale và reach
- Resources (facilities, funding)
- Legitimacy
- Sustainability (institutionalization)

Levels:
- National (ministries)
- Provincial (departments)
- District/ward (local authorities)

Engagement: MOUs, joint programs, support initiatives
```

#### 2.2.4. Academic partnerships
```
Value:
- Research expertise
- Data analysis
- Innovation
- Student talent (volunteers, interns)

Partners:
- Universities (research projects)
- Research institutes (technical support)
- Other schools (collaboration, resource sharing)

Engagement: Research projects, joint initiatives, internships
```

## 3. PARTNER SELECTION

### 3.1. Selection criteria

#### 3.1.1. Evaluation framework
```
PARTNER EVALUATION CRITERIA

Alignment:
- Mission và values compatible? (High priority)
- Objectives shared?
- Target beneficiaries overlap?

Capacity:
- Track record (proven delivery)?
- Resources adequate?
- Expertise needed?
- Geographic coverage?

Reputation:
- Credibility với community?
- Ethical standards?
- Financial transparency?
- No controversy?

Fit:
- Communication style compatible?
- Working culture similar?
- Commitment level matched?
- Flexibility?

Score each: 1-5
Minimum: ≥ 3.5 average to proceed
```

### 3.2. Due diligence

#### 3.2.1. Background check
```
Verify:
- Legal status (registered?)
- Financial health (audited statements)
- References (3 partners/clients)
- Track record (past projects)
- Leadership (background, reputation)
- Compliance (regulations, taxes)

Sources:
- Public records
- Website, annual reports
- References
- Site visits
```

## 4. PARTNERSHIP DEVELOPMENT

### 4.1. Relationship building

#### 4.1.1. Initial engagement
```
Steps:
1. Research (understand partner)
2. Reach out (email, meeting request)
3. Exploratory meeting (capabilities, interests)
4. Identify synergies (where collaborate?)
5. Propose collaboration (specific idea)
6. Negotiate terms
7. Formalize (MOU/agreement)

Timeline: 2-6 tháng
```

### 4.2. Partnership agreement

#### 4.2.1. Memorandum of Understanding (MOU)
```
MOU STRUCTURE

1. Parties (school và partner)
2. Background (context, rationale)
3. Objectives (what achieve together)
4. Scope of collaboration:
   - Activities
   - Roles và responsibilities
   - Contributions (each party)
5. Duration (start/end dates)
6. Governance:
   - Coordination mechanism
   - Decision-making
   - Communication
7. Financial arrangements (if any)
8. Intellectual property (if relevant)
9. Confidentiality
10. Termination clause
11. Dispute resolution
12. Signatures

Length: 3-5 trang
Legal review: Recommended
```

## 5. PARTNERSHIP MANAGEMENT

### 5.1. Coordination

#### 5.1.1. Communication structure
```
Liaison officers:
- School: CSR Manager or designate
- Partner: Designated contact

Regular touchpoints:
- Weekly: Email updates (during projects)
- Monthly: Coordination calls
- Quarterly: Face-to-face meetings
- Annually: Strategic review

Tools: Email, phone, WhatsApp, Zoom
```

#### 5.1.2. Joint planning
```
Collaborative planning:
- Annual work plan (together)
- Project plans (joint ownership)
- Budget (transparent, agreed)
- M&E framework (shared metrics)
- Reporting (mutual accountability)

Approach: Co-creation, not directive
```

### 5.2. Conflict resolution

#### 5.2.1. Common issues
```
Typical conflicts:
- Misaligned expectations
- Communication breakdowns
- Resource commitments not met
- Credit/recognition disputes
- Strategic differences

Prevention:
- Clear MOU
- Regular communication
- Transparency
- Flexibility
- Mutual respect
```

#### 5.2.2. Resolution process
```
Steps:
1. Identify issue early
2. Direct discussion (liaisons)
3. Joint problem-solving session
4. Mediation (if needed, neutral party)
5. Escalate to leadership (last resort)
6. Termination (only if unresolvable)

Principle: Preserve relationship, find win-win
```

## 6. PARTNER SUPPORT

### 6.1. Capacity building

#### 6.1.1. Support types
```
Provide:
- Training (skills needed for projects)
- Resources (materials, equipment loan)
- Expertise (volunteer professionals)
- Networking (connect to others)
- Co-funding (help fundraise)

Approach: Reciprocal (they also support us)
```

### 6.2. Recognition

#### 6.2.1. Acknowledge partners
```
Ways:
- Credit trong all communications
- Logo placement (materials, events)
- Thank you events (annual)
- Awards (outstanding partner)
- Features (website, social media, reports)
- References (for their proposals)

Principle: Generous recognition, shared success
```

## 7. PARTNERSHIP EVALUATION

### 7.1. Performance assessment

#### 7.1.1. Annual review
```
Assess jointly:
- Objectives achieved?
- Contributions met? (both parties)
- Collaboration quality?
- Impact realized?
- Challenges faced?
- Lessons learned?
- Continue partnership? Adjust?

Format: Meeting + written summary
Outcome: Renew / Adjust / End partnership
```

### 7.2. Impact measurement

#### 7.2.1. Partnership metrics
```
Track:
- Projects completed (together)
- Beneficiaries reached
- Resources contributed (each)
- Outcomes achieved
- Efficiency gains (vs. solo)
- Relationship quality (surveys)

Goal: Demonstrate partnership value
```

## 8. PARTNERSHIP PORTFOLIO

### 8.1. Portfolio management

#### 8.1.1. Active partnerships
```
Maintain:
- Inventory (all partners, status)
- Diversity (types, sectors)
- Balance (time, resources)
- Quality over quantity (better 5 than 20 weak)

Review: Quarterly (portfolio health)
```

### 8.2. Strategic partnerships

#### 8.2.1. Long-term strategic partners
```
Criteria:
- Multi-year commitment
- Multiple projects (portfolio)
- Strategic alignment (deep)
- Resource commitment (significant)
- Joint planning (annual)

Benefits:
- Efficiency (established relationship)
- Impact (sustained engagement)
- Innovation (co-create)

Target: 3-5 strategic partners
```

## 10. CHỈ SỐ ĐÁNH GIÁ

```
Portfolio:
- Active partnerships: 10-15
- Strategic partnerships: 3-5
- Partner types: All 4 types represented
- Partnership satisfaction: ≥ 4.0/5.0

Performance:
- Projects with partners: ≥ 70%
- Partnership outcomes achieved: ≥ 80%
- Renewals: ≥ 80%
- Conflicts resolved: 100%

Value:
- Leverage (partner contribution / school input): ≥ 1.5x
- Efficiency gains: Measurable
- Impact enhancement: Demonstrated
```
