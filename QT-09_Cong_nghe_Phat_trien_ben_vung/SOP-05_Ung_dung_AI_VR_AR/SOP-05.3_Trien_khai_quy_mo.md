# SOP-05.3: TRIỂN KHAI QUY MÔ

## 1. MỤC ĐÍCH
Quy định quy trình triển khai công nghệ AI/VR/AR ra toàn trường sau pilot thành công, đảm bảo:
- Rollout có tổ chức và hiệu quả
- Minimize disruption
- Adoption cao
- Quality maintained
- Sustainable operations

## 2. ROLLOUT STRATEGY

### 2.1. Phased rollout (Khuyến nghị)

#### 2.1.1. Rollout approach
```
Phase 1 - Early adopters (Tháng 1-2):
- Pilot teachers (đã quen)
- Volunteer teachers
- Target: 20-30% teachers

Phase 2 - Early majority (Tháng 3-4):
- Encouraged adoption
- More training
- Target: 50-60% teachers

Phase 3 - Late majority (Tháng 5-6):
- Stronger push
- Peer pressure
- Target: 80-90% teachers

Phase 4 - Laggards (Tháng 7+):
- Mandates (nếu cần)
- Extra support
- Target: 100%
```

#### 2.1.2. By grade/subject
```
Option A - By grade:
Quarter 1: Grades 6-8
Quarter 2: Grades 9-10
Quarter 3: Grades 11-12
Quarter 4: Grades 1-5

Option B - By subject:
Quarter 1: STEM subjects
Quarter 2: Languages
Quarter 3: Arts
Quarter 4: All subjects

Choose based on:
- Technology type
- Resource constraints
- Complexity
```

### 2.2. Big bang approach (Nếu simple)

#### 2.2.1. Khi nào dùng
```
Appropriate if:
- Simple technology
- High readiness
- Limited complexity
- Strong support
- Urgent need

Example:
- AI chatbot (simple)
- AR app (easy to use)
```

## 3. IMPLEMENTATION PROCESS

### 3.1. Pre-rollout (2-3 tháng)

#### 3.1.1. Infrastructure preparation
```
Procurement:
□ Order equipment (VR headsets, tablets)
□ Purchase licenses
□ Provision infrastructure
□ Setup networks
□ Test performance

Logistics:
□ Storage space
□ Charging stations
□ Distribution plan
□ Maintenance plan
```

#### 3.1.2. Content development
```
Create:
- Lesson plans (sử dụng tech)
- Learning activities
- Assessment rubrics
- Student guides
- Parent guides

Curate:
- Existing content
- Third-party resources
- Templates
- Best practices
```

#### 3.1.3. Training program
```
Teacher training:
Wave 1 (Early adopters): Intensive (8 giờ)
Wave 2 (Early majority): Standard (4 giờ)
Wave 3+: Streamlined (2 giờ) + self-paced

Content:
- Technology overview
- Pedagogical strategies
- Hands-on practice
- Lesson planning
- Troubleshooting
- Support resources
```

### 3.2. Rollout execution

#### 3.2.1. Distribution
```
Process:
1. Schedule distribution (by phase)
2. Setup sessions (hands-on)
3. Verify functionality
4. Collect inventory
5. Provide support materials
6. Follow-up check (1 tuần)
```

#### 3.2.2. Go-live support
```
Hypercare (First 2-4 tuần):
- Extended support hours
- On-site assistance
- Quick response
- Daily check-ins
- Issue tracking
- Rapid fixes
```

### 3.3. Monitoring và adjustment

#### 3.3.1. Early feedback
```
Collect after 2 tuần:
- Quick survey (5 phút)
- Issues log
- Usage data
- Teacher check-ins

Analyze:
- What's working?
- What's not?
- Quick fixes?
- Larger changes needed?

Adjust:
- Configuration tweaks
- Additional training
- Process improvements
- Communication
```

## 4. SCALING CONSIDERATIONS

### 4.1. Capacity planning

#### 4.1.1. Equipment needs
```
Calculate:
- Students: [X]
- Student:device ratio: [1:Y]
- Devices needed: [X/Y]
- Buffer (breakage, growth): +15%
- Total: [Z devices]

Phased procurement:
- Phase 1: 30%
- Phase 2: 30%
- Phase 3: 25%
- Phase 4: 15%
```

#### 4.1.2. Infrastructure scaling
```
Assess:
- Network bandwidth (VR bandwidth-heavy)
- WiFi access points
- Charging infrastructure
- Storage space (physical và digital)
- Support capacity

Upgrade nếu cần:
- Before rollout phases
- Monitor utilization
- Scale proactively
```

### 4.2. Cost management

#### 4.2.1. Budget scaling
```
Pilot costs × Scale factor + Efficiency gains

Example:
Pilot: 50 triệu for 90 students
Scale: 1000 students
Naive scale: 50M × (1000/90) = 556M

With efficiencies:
- Bulk discount: -15%
- Shared resources: -10%
- Process improvements: -5%

Actual: 556M × 0.7 = 389M
```

#### 4.2.2. Funding strategy
```
Sources:
- Operating budget (ongoing)
- Capital budget (equipment)
- Grants (education innovation)
- Sponsorships (corporate partners)
- Parent contributions (optional)
```

## 5. CHANGE MANAGEMENT

### 5.1. Resistance handling

#### 5.1.1. Common objections
```
"Too complicated":
→ Simplify, better training, support

"No time to learn":
→ Time-saving benefits, reduce other work

"Students will misuse":
→ Clear guidelines, monitoring, consequences

"Not proven":
→ Share pilot results, research evidence

"Prefer traditional":
→ Respect, gradual adoption, show value
```

#### 5.1.2. Strategies
```
- Communicate benefits clearly
- Provide adequate support
- Celebrate successes
- Share best practices
- Respect preferences (initially)
- Mandates only if necessary
```

### 5.2. Champion network

#### 5.2.1. Expand champions
```
From pilot:
- Pilot teachers become champions
- Train-the-trainer model
- Mentor new users

Recruit more:
- Early adopters trong each phase
- 1-2 per department
- Recognition và incentives
```
