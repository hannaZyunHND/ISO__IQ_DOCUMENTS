## 1. MỤC ĐÍCH
Quy định quy trình đánh giá hiệu quả và mở rộng ứng dụng công nghệ, đảm bảo:

```
Metrics:

- Grade improvements

- Concept understanding
```

### 3.3. ROI calculation

#### 3.3.1. Simple ROI
```
ROI = (Total Benefits - Total Costs) / Total Costs × 100%

Example:
Costs (3 năm): 500 triệu
Benefits (3 năm): 800 triệu
ROI = (800-500)/500 × 100% = 60%

Interpretation:
- >50%: Good
- >100%: Excellent
- <0%: Loss
```

#### 3.3.2. Payback period
```
Calculate:
- How long to recover investment?
- When become cash-positive?

Target: ≤ 3 năm
```

## 4. EXPANSION PLANNING

### 4.1. Identify expansion opportunities

#### 4.1.1. Horizontal expansion
```
Current: Math Grade 6-8 using AI
Expand to:
- Math Grade 9-12
- Science Grade 6-8
- Other subjects

Rationale:
- Proven value
- Similar contexts
- Economies of scale
```

#### 4.1.2. Vertical expansion
```
Current: Basic AI tutoring
Expand to:
- Advanced AI (personalization)
- AI content creation
- AI assessment
- Predictive analytics

Rationale:
- Infrastructure in place
- Users familiar
- Incremental value
```

#### 4.1.3. New applications
```
Successful VR in Science → Try VR in:
- History (historical sites)
- Geography (world exploration)
- Art (museum tours)
- Language (cultural immersion)

Evaluation:
- Similar feasibility
- Teacher interest
- Student benefit
- Cost reasonable
```

### 4.2. Expansion process

#### 4.2.1. Mini-pilot
```
For expansion:
1. Small trial (1-2 classes)
2. Duration: 4-8 tuần
3. Evaluate quickly
4. Adjust and scale

Faster than full pilot:
- Technology proven
- Infrastructure exists
- Focus on new context
```

#### 4.2.2. Phased rollout
```
Quarter 1: Phase 1 (30% of target)
Quarter 2: Phase 2 (additional 30%)
Quarter 3: Phase 3 (additional 30%)
Quarter 4: Phase 4 (final 10% + optimization)
```
