
### 3.2. Safety training

#### 3.2.1. VR safety
```
Rules:
✅ Clear play area (2m × 2m)
✅ Sit if feeling dizzy
✅ Take breaks (every 15 phút)
✅ Report discomfort immediately
✅ Follow teacher instructions
✅ Respect equipment

Contraindications:
- Motion sickness history
- Eye problems (consult doctor)
- Epilepsy (photosensitive)
- Very young (<10 years)
```

#### 3.2.2. Responsible use
```
AI ethics for students:
- AI is tool, not replacement for thinking
- Verify AI information
- Don't over-rely
- Understand limitations
- Credit AI (nếu used trong work)

Digital citizenship:
- Appropriate content
- Respect others
- Privacy awareness
- Report issues
```


#### 4.1.2. Response times
```
P1 - Class disrupted: 15 phút
P2 - Feature broken: 1 giờ
P3 - Minor issue: 4 giờ
P4 - Questions: 1 ngày
```

### 4.2. Common issues

#### 4.2.1. Technical issues
```
VR issues:
- Headset not connecting → Check batteries, pairing
- Lag/choppy → Check WiFi, close apps
- Controllers not working → Recalibrate, replace batteries

AR issues:
- Markers not detected → Lighting, camera
- Models not loading → Update app, check internet
- Crashes → Restart app, update OS

AI issues:
- Slow responses → Server load, check internet
- Wrong answers → Report, feedback loop
- Login problems → Reset, check credentials
```

#### 4.2.2. Pedagogical challenges
```
Issues:
"Students distracted":
→ Clear learning objectives, structured activities

"Too much time setup":
→ Streamline procedures, student helpers

"Hard to assess":
→ Clear rubrics, built-in analytics

"Not all students have devices":
→ Rotation system, school devices
```

### 4.3. Device management

#### 4.3.1. Inventory management
```
Track:
```
