**Bước 1: Phần Demo cơ bản (Chi tiết)**

**A. Cách đăng nhập:**

```
Bước 1: Mở trình duyệt (Chrome khuyến khích)
Bước 2: Vào link: https://drive.google.com
Bước 3: Click "Shared drives" (Bên trái)
Bước 4: Tìm "THƯ VIỆN SỐ IQ SCHOOL"
Bước 5: Click vào → Vào được rồi!

Hoặc:
Bước 1: Mở File Explorer
Bước 2: Vào ổ G:\ (Google Drive)
Bước 3: Mở thư mục "THƯ VIỆN SỐ..."
```

**Mẹo:** Bookmark link để lần sau vào nhanh!

**B. Cách duyệt thư mục:**

```
Ví dụ: Tìm giáo án Toán lớp 3

Bước 1: Mở "01_GIÁO ÁN"
Bước 2: Mở "Tieu_hoc"
Bước 3: Mở "Lop_3"
Bước 4: Mở "Toan"
Bước 5: Thấy danh sách giáo án!
```

**C. Cách tìm kiếm (Nhanh hơn duyệt!):**

```
Bước 1: Click vào ô "Search" (Góc trên)
Bước 2: Gõ từ khóa: "Phép nhân lớp 3"
Bước 3: Nhấn Enter
Bước 4: Thấy danh sách kết quả!
Bước 5: Click vào file muốn xem
```

**Tips tìm kiếm hiệu quả:**
- Dùng tag: Tìm `#Toán #Lớp3` → Ra tất cả TL Toán lớp 3
- Dùng tên tác giả: `Nguyễn Văn A` → Ra TL của GV này
- Dùng năm: `2024` → Ra TL mới nhất

**D. Cách xem file:**

```
Cách 1: Xem online (Không tải về - Nhanh!)
  - Click đúp vào file
  - Google Drive tự mở
  - PDF/Slide: Xem ngay
  - Video: Play ngay
  
Cách 2: Tải về máy
  - Click phải file → "Download"
  - Chọn thư mục lưu trên máy
  - Chờ tải xong → Mở file từ máy
```

**Khi nào xem online? Khi nào tải về?**

| **Tình huống** | **Khuyến nghị** |
|---|---|---|
| Xem nhanh, 1 lần | Xem online (Không tải) |
| Dùng nhiều lần, Offline | Tải về |
| File lớn (>50MB), Wifi chậm | Xem online (Không tải hết) |
